# Sara Elsharkawy — AI/ML Portfolio

A modern responsive portfolio built with React, Vite, Tailwind CSS, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Personalize

1. Add your real photo as `public/profile.jpg`.
2. Add your CV as `public/Sara_Elsharkawy_CV.pdf`.
3. Replace placeholder GitHub links in `src/main.jsx`.
4. Replace the placeholder email and LinkedIn URL.
5. Replace project emoji blocks with real project screenshots if desired.

## Build

```bash
npm run build
```

The production files will be generated in `dist/`.
